# 光栅耦合器 (Grating Coupler)

## 概述

光栅耦合器是一种重要的光子学器件，用于实现光纤与集成光子芯片之间的高效光耦合。通过周期性的光栅结构，将光纤中的光信号耦合进入芯片上的波导。

## 工作原理

光栅耦合器利用周期性结构产生的衍射效应工作：
- 入射光照射到光栅表面
- 光栅的周期性结构产生衍射
- 特定衍射级次的光被耦合进入波导

耦合效率取决于：
1. 光栅周期
2. 刻蚀深度
3. 占空比
4. 入射角度

## 设计参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 波长 | 1550 nm | C波段通信波长 |
| 光栅周期 | 600-700 nm | 决定耦合波长 |
| 刻蚀深度 | 70-150 nm | 影响耦合强度 |
| 占空比 | 0.4-0.6 | 影响衍射效率 |
| 入射角度 | 8-15° | 通常为垂直或倾斜入射 |

## 性能指标

- **耦合效率**: 衡量光信号从光纤进入波导的比例，目标 >70%
- **带宽**: 有效耦合的波长范围，典型值 50-100 nm
- **插入损耗**: 光信号在耦合过程中的损耗
- **回波损耗**: 反射光的比例

## 设计方法

### 传统方法
使用解析公式和经验参数进行设计，需要多次迭代优化。

### 拓扑优化
基于伴随变量方法，自动优化结构分布以实现目标性能。

### 深度学习
使用神经网络（TNN、MDN、CGAN、HiLab）进行逆向设计：
1. TNN: 快速原型设计，适合简单场景
2. MDN: 处理一对多映射问题
3. CGAN: 生成多样化设计方案
4. HiLab: 高质量优化设计

## 制造约束

- 最小特征尺寸：通常 > 100 nm
- 最小间距：通常 > 100 nm
- 刻蚀深度限制：取决于工艺
- 设计规则检查 (DRC) 需要通过

## 应用场景

1. 光纤到芯片耦合
2. 光通信系统
3. 光子集成电路测试
4. 量子光子学
