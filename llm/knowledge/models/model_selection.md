# 模型选择指南

本文档帮助您选择最适合的逆向设计模型。

## 模型概览

| 模型 | 全称 | 核心特点 | 推荐场景 |
|------|------|----------|----------|
| TNN | Tandem Neural Network | 快速、简单 | 快速原型 |
| MDN | Mixture Density Network | 处理多解 | 不确定设计空间 |
| CGAN | Conditional GAN | 多样性 | 设计探索 |
| PINN | Physics-Informed NN | 物理约束 | 数据稀缺 |
| HiLab | VAE + Bayesian | 高质量 | 最优设计 |

## 详细说明

### TNN (串联神经网络)

**架构**:
```
性能目标 → 逆向网络 → 设计参数 → 正向网络 → 预测性能
```

**优点**:
- 训练快速收敛
- 推理速度快
- 实现简单

**缺点**:
- 只能处理一对一映射
- 无法处理设计空间的多解问题
- 对抗样本敏感

**适用场景**:
- 设计空间相对简单
- 有充足的训练数据
- 需要快速得到初步结果

**配置建议**:
```python
{
    "type": "tnn",
    "hidden_dims": [256, 512, 256],
    "activation": "relu",
    "epochs": 100,
    "learning_rate": 0.001
}
```

---

### MDN (混合密度网络)

**架构**:
```
性能目标 → MDN → 多个高斯分量(均值、方差、权重) → 设计参数分布
```

**优点**:
- 可以处理一对多映射
- 提供不确定性估计
- 能够发现多个设计方案

**缺点**:
- 训练相对复杂
- 需要选择合适的分量数
- 对超参数敏感

**适用场景**:
- 设计空间存在多个局部最优解
- 需要了解设计的不确定性
- 希望获得多种设计方案

**配置建议**:
```python
{
    "type": "mdn",
    "hidden_dims": [256, 512, 256],
    "n_components": 5,
    "epochs": 150,
    "learning_rate": 0.001
}
```

---

### CGAN (条件生成对抗网络)

**架构**:
```
噪声 z + 条件 c → 生成器 → 设计
设计 + 条件 c → 判别器 → 真/假
```

**优点**:
- 生成多样化的设计
- 可以探索整个设计空间
- 生成高质量样本

**缺点**:
- 训练不稳定
- 需要调参经验
- 可能出现模式崩溃

**适用场景**:
- 需要多种设计选项
- 探索创新设计方案
- 数据分布复杂

**配置建议**:
```python
{
    "type": "cgan",
    "generator_dims": [256, 512, 256],
    "discriminator_dims": [256, 128, 1],
    "latent_dim": 64,
    "epochs": 200,
    "learning_rate": 0.0002
}
```

---

### PINN (物理信息神经网络)

**架构**:
```
设计参数 → 神经网络 → 预测性能
              ↑
         物理方程约束 (Maxwell方程)
```

**优点**:
- 物理约束保证结果合理
- 需要较少的训练数据
- 泛化能力强

**缺点**:
- 训练速度慢
- 需要明确的物理方程
- 对物理模型准确性要求高

**适用场景**:
- 训练数据稀缺
- 物理规律明确
- 需要物理可解释性

**配置建议**:
```python
{
    "type": "pinn",
    "hidden_dims": [256, 512, 512, 256],
    "physics_weight": 0.1,
    "epochs": 200,
    "learning_rate": 0.001
}
```

---

### HiLab (VAE + 贝叶斯优化)

**架构**:
```
设计 → VAE编码器 → 潜在向量 → VAE解码器 → 重建设计
潜在向量 → 代理模型 → 性能预测
贝叶斯优化 → 在潜在空间搜索最优解
```

**优点**:
- 高质量设计
- 支持多目标优化
- 样本效率高

**缺点**:
- 计算成本高
- 需要较多初始数据
- 实现复杂

**适用场景**:
- 追求最优设计
- 多目标优化
- 有计算资源支持

**配置建议**:
```python
{
    "type": "hilab",
    "vae_hidden_dims": [256, 512],
    "latent_dim": 64,
    "bayesian_iterations": 50,
    "acquisition_function": "ei",
    "epochs": 100
}
```

## 选择决策树

```
开始
  │
  ├─ 有充足训练数据?
  │   ├─ 是 → 设计空间复杂?
  │   │   ├─ 是 → 需要多样性?
  │   │   │   ├─ 是 → CGAN
  │   │   │   └─ 否 → MDN
  │   │   └─ 否 → 追求最优?
  │   │       ├─ 是 → HiLab
  │   │       └─ 否 → TNN
  │   └─ 否 → 物理规律明确?
  │       ├─ 是 → PINN
  │       └─ 否 → 先收集数据或使用仿真
```
